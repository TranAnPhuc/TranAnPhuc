## 👨‍💻 About Me

I'm a Software Engineer and Full-stack Web Developer with hands-on experience building and maintaining internal enterprise applications.

My current development journey focuses on combining **backend engineering**, **modern frontend development**, and **AI-assisted software development**.

I enjoy turning real business problems into maintainable software rather than building projects only for demonstration.

### What I currently work with

- 🏢 Enterprise internal applications
- 🔧 C# / ASP.NET Core
- ⚛️ React / TypeScript
- 🗄️ SQL Server / PostgreSQL
- 🚀 RESTful APIs and backend architecture
- 📱 React Native / mobile development
- 🤖 AI-assisted development and AI Agents
- 🧠 Clean Code, system design and software engineering practices

### My development philosophy

> **Use AI to accelerate development, but understand the code well enough to maintain it without AI.**

I use AI as a development partner for exploration, implementation, refactoring and documentation while keeping the focus on understanding the underlying architecture and engineering decisions.
